This project is a lightweight, full-stack e-commerce inventory management system that I built to help store administrators easily manage their products. For the frontend, I used plain HTML and JavaScript styled with Tailwind CSS to create a clean, responsive dashboard where users can instantly add, edit, or delete items, and even filter or sort the inventory in real-time. To power this, I wrote a Java Spring Boot REST API for the backend, relying on a thread-safe ConcurrentHashMap to ensure that multiple admin requests can be processed at the same time without any data corruption. Finally, I containerized the entire application using Docker and deployed it live on Render, making it a complete, end-to-end solution.
